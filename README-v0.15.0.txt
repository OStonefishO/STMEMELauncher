MEME Launcher v0.15.0

本项目使用 SignPath Foundation 提供的免费代码签名服务。
This project uses the free code signing provided by SignPath Foundation (https://signpath.org/).

### 这一版
- 主页/设置可以扫描 Java、自动匹配、手动选 java.exe；版本不对会先问你再启动
- 版本可重命名、可写备注（整合包导出更方便）
- 安装可以同时进行多个，带取消按钮；资源个别失败不再拖死安装
- 整合包点安装直接下载并导入成版本
- 修 mods\mods 套娃、大标题版本号解析、下载卡死

### 提示
Windows 11 智能应用控制会拦未签名 exe，详见 https://github.com/OStonefishO/STMEMELauncher/blob/main/docs/SMART-APP-CONTROL.md
