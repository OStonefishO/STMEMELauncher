# 隐私说明（Privacy Policy）

MEME Launcher 是一个本地运行的 Minecraft 启动器。**它不收集、不上传任何使用数据。**

## 不收集什么

- 没有遥测、没有埋点、没有崩溃上报服务器
- 不会上传你的游戏目录、模组列表、聊天记录或硬件信息
- 没有广告，也没有第三方统计 SDK

## 存在你电脑上的数据

| 数据 | 位置 | 用途 |
|---|---|---|
| 启动器设置、账号列表 | `%APPDATA%\MEMELauncher\config.json` | 记住你的选择 |
| 微软 / LittleSkin 登录令牌 | 同上（仅本地） | 免重复登录 |
| 网页缓存（B 站、皮肤预览） | `%LOCALAPPDATA%\MEMELauncher` | 加速加载 |

这些文件只在本机，随时可以整个删掉，删掉等同于重装启动器。

## 会联网的场合

- 下载游戏 / 模组 / 整合包（Mojang、BMCLAPI 镜像、Modrinth、CurseForge）
- 检查更新（GitHub / Gitee）
- 你在「娱乐」页打开 B 站、或在音乐播放器里匹配歌词（网易云 / QQ 音乐 / 酷狗）
- 你主动登录微软账号或 LittleSkin

以上请求都只携带完成该操作所需的最少信息，不含任何统计标识。
