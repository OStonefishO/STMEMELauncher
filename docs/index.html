BLOCKED?

被 Windows 拦住了？

Windows 11 的「智能应用控制」只放行有数字签名的程序，本作没有买证书（免费签名申请未通过），所以会被拦。按下面关掉即可。

1

打开 Windows 安全中心

开始菜单搜「Windows 安全中心」，或按 Win 键直接输入「安全」。

2

进入「应用和浏览器控制」

在左侧列表点它，再点「智能应用控制设置」。

3

把智能应用控制关掉

选择「关闭」并确认。注意：关掉后要重装系统才能再打开，介意的话换一台没开这个功能的电脑。

完整图文（含「不关 SAC 的替代做法」）见 SMART-APP-CONTROL.md。

💡 关闭后如果还是打不开：右键 exe → 属性 → 底部看有没有「解除锁定」并勾上；或者把 exe 从下载目录挪到 D 盘再试。

FAQ

常见问题

需要自己装 Java 吗？

不需要。启动器会扫描本机 Java，找不到匹配版本时会问你要不要自动下载安装。

提示「已阻止可能不安全的应用」怎么办？

那是 Windows 11 的智能应用控制，只放行有数字签名的 exe。文档里有三种处理方式，最省事的是在「Windows 安全中心 → 应用和浏览器控制」里关掉它。

从别处复制的存档为什么在游戏里看不到？

因为版本隔离开启时，游戏读的是 versions\版本名\saves，不是根目录的 saves。版本页有「导入存档」，文件夹或 zip 都能直接放对位置。

支持正版登录吗？

支持微软账号与外置登录（authlib-injector），也可以离线模式。

Q&A

问答板块

玩家最常问的几件事，答在这里；没答到的直接来问。

Q：下载很慢 / 卡住不动怎么办？

A：先切到 Gitee 镜像下载；启动器里的「下载与镜像」默认走 BMCLAPI 国内镜像，若仍慢可以换成自己的镜像地址。

Q：必须用正版账号吗？

A：不必须。支持微软正版登录、外置登录（LittleSkin 等 authlib-injector 皮肤站）和离线模式，离线名在「账号」页管理。

Q：整合包能直接装吗？

A：能。在「内容 → 整合包」里点安装，会下载 .mrpack / zip 并自动导入成一个版本，失败可以在下载管理里取消重来。

Q：我的存档 / 配置存在哪？

A：开启版本隔离时在 versions\版本名\ 下（saves、mods、config 都在里面）；关掉隔离则用 .minecraft 根目录。配置本身在 %APPDATA%\MEMELauncher。

Q：支持哪些 MC 版本和加载器？

A：从 1.7 到最新的快照都行；Fabric / Forge / NeoForge / Quilt / OptiFine 一键安装，Java 会自动匹配（没有就帮你下）。

Q：启动就退出 / 报错看不懂？

A：启动器会给出人话结论并保留完整日志（%APPDATA%\MEMELauncher\logs）。点「导出报告」发到 Issues，我按日志定位。
