# 被 Windows 拦住了怎么办

> 现象：双击 `MEME启动器.exe`，弹出「智能应用控制已阻止可能不安全的应用」，
> 只说「无法验证其发布者」，除了「正常」和「从 Microsoft Store 获得应用」没有别的按钮。

这不是启动器带了病毒，而是 **Windows 11 的「智能应用控制」(Smart App Control)** 不认识这个 exe。

---

## 为什么会被拦

Smart App Control（简称 SAC）是 Windows 11 22H2 之后新装系统默认开启的一道闸门，规则很简单：

- 有**受信任的数字签名** → 放行
- 没有签名、也没有微软的云信誉记录 → **直接拦掉，且不给「仍要运行」的选项**

MEME 启动器目前是**未签名**的个人项目（代码签名证书是付费的），所以只要对方系统开着 SAC，就一定会被拦。
Windows 10、以及手动装过系统 / 关闭过 SAC 的机器不会遇到。

---

## 给玩家：三种办法

### 办法一：关掉智能应用控制（最直接）

1. 开始菜单搜 **Windows 安全中心**（或 `windowsdefender://`）
2. 左边点 **应用和浏览器控制**
3. 点 **智能应用控制设置**
4. 选择 **关闭** → 确认

> ⚠️ 注意：SAC 一旦关闭，**不重装系统就回不去了**（微软的设计）。
> 如果你的电脑平时装的都是正规软件，关掉它风险不大；介意的话用办法二 / 三。

### 办法二：换一台没开 SAC 的电脑 / 用 Windows 10

SAC 只在「全新安装的 Windows 11」上默认开启。老系统升级上来的一般没有这一项。

### 办法三：用微软的审核通道

弹窗里的「Microsoft 将审核该应用」是自动上报，等微软人工过一遍（通常几天到几周），
过审后其他人下载同一个文件就不会再被拦。

---

## 给作者：想彻底解决只能签名

SAC 和 SmartScreen 都只认**代码签名证书**，没有别的技术绕法（打包成 zip、换个格式、加壳都不行）。

| 方案 | 成本 | 说明 |
|---|---|---|
| **SignPath Foundation** | 免费 | 面向开源项目的免费签名服务，需要 GitHub 公开仓库 + 申请审核，签发的是受信任证书 |
| **Azure Trusted Signing** | 约 $9.99/月 | 微软自家的签名服务，需要企业/个人身份验证 |
| **OV 代码签名证书**（DigiCert / Sectigo 等） | 约 ¥1000–2000/年 | 最通用，配合 USB 令牌签名 |
| **EV 代码签名证书** | 约 ¥3000+/年 | 立刻获得 SmartScreen 信誉，硬件令牌 |

拿到证书后，在 `scripts/publish-release.ps1` 里加上签名步骤即可（脚本已预留）：

```powershell
.\scripts\publish-release.ps1 -Version 0.14.0 -GiteeToken <token> `
    -SignPfx "D:\cert\meme.pfx" -SignPassword "<密码>"
```

没给 `-SignPfx` 时脚本会跳过签名，行为和现在一样。

## 已经下载了但打不开的临时办法

- 别双击，先在文件上**右键 → 属性**，如果底部有「解除锁定」就勾上（这只解决「从网络下载」的标记，不解决 SAC）。
- 或者把 exe 复制到 `D:\` 这种本地目录再试（有些拦截是跟下载目录绑定的）。
- 还不行就是 SAC，只能按上面的办法一处理。
